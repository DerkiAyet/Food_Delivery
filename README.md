# Food Delivery App

A food delivery mobile application built with **Flutter**. Browse the menu, customize order, pay, and follow delivery in real time, all in a clean, themeable interface.

## Features

- User login and registration
- Home page with a browsable food menu
- Detailed food pages with options and add-ons
- Shopping cart with quantity management
- Payment flow
- Settings page with light/dark theme switching
- Clean state management with providers
---

## Tech Stack

- **Framework:** [Flutter](https://flutter.dev/)
- **Language:** [Dart](https://dart.dev/)
- **State management:** [Provider](https://pub.dev/packages/provider)
- **Backend:** [Firebase](https://firebase.google.com/) (Authentication, Firestore)

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.x or later)
- An editor such as Android Studio or VS Code
- An emulator or a physical device

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/DerkiAyet/Food_Delivery.git

# 2. Move into the project
cd Food_Delivery

# 3. Install dependencies
flutter pub get

# 4. Run the app
flutter run
```
